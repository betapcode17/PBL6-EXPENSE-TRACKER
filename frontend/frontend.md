# Mobile Frontend Documentation - PBL6 Expense Tracker

## 1. Giới thiệu tổng quan
Ứng dụng di động quản lý chi tiêu cá nhân thông minh, phát triển trên nền tảng **Flutter (Dart)** hỗ trợ cả Android và iOS. Ứng dụng cung cấp giao diện trực quan để người dùng theo dõi thu chi, quản lý ngân sách, và số hóa hóa đơn thông qua tính năng chụp ảnh nhận dạng tự động.

## 2. Công nghệ sử dụng
- **Framework:** Flutter (3.x+)
- **Language:** Dart
- **State Management:** Riverpod / Bloc / Provider
- **Networking:** Dio / Http client (tương tác với Backend REST API)
- **Image Picker & Camera:** `image_picker`, `camera`
- **Charts:** `fl_chart` (biểu đồ thống kê tròn/cột)
- **Local Storage:** `shared_preferences` / `flutter_secure_storage` (lưu trữ JWT token và cấu hình cá nhân)
